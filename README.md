# LG Cast Helper 📺

Android helper app for connecting a phone to a compatible LG Smart TV.

## Features
- Checks whether the phone currently has a network connection.
- Opens Android Wi-Fi settings.
- Attempts to open the phone's built-in Cast / Wireless Display controls.
- Gives simple LG TV setup instructions.

## Important
The app does not bypass Android or LG TV casting restrictions. Actual screen mirroring depends on the phone and TV supporting a compatible protocol (such as Miracast/Wi-Fi Display or another supported receiver).

For best results, put the phone and TV on the same Wi-Fi network and enable Screen Share / Screen Mirroring on the TV.
